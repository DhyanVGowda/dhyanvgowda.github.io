Computer and Information Research Scientist (Software Engineering and Applied AI) - MG Health Tech

McKinney, Texas | February 2026 - Present

Home sleep testing: Developing the capture engine for a home sleep testing mobile app, recording overnight SpO2, pulse rate, a 125 Hz PPG waveform, and activity from a Bluetooth pulse oximeter, with fault-tolerant background capture and session recovery. Built the sleep-study server and data processing pipeline (Python, AWS Lambda) that verifies uploads by SHA-256, stitches 15-minute segments, checks quality, and converts packet logs into European Data Format (EDF) for EnsoData sleep scoring. Designed the API linking the sleep-study server to the MySleepReport physician portal: study orders, EDF handoff through short-lived download links, and scoring outcomes.


VitalWeave: Led integration of Bluetooth Low Energy (BLE) medical devices (blood pressure monitor, ECG recorder) into the VitalWeave React Native app (App Store, Google Play), sending readings to physicians. Prototyped a wellness analytics dashboard that turns wearable ECG/PPG signals into daily recovery, strain, sleep, stress, and HRV scores using open-source signal processing and ML, with an AI chatbot grounded in each user's data.


AI voice agent: Co-built a real-time AI voice agent (asyncio, Deepgram ASR, GPT-4.1-mini function calling, Telnyx) that answers calls 24/7 for multiple clinics, handling appointment requests, refills, cancellations, payment inquiries, and clinic questions. Engineered its HIPAA and TCPA safeguards: two-phase SMS consent, append-only audit logs, protected health information (PHI) masking, signed webhooks, and fail-closed opt-outs.


AroCord: Productionized the AroCord electronic health record (EHR) summarizer: GPT-4o summaries checked by GPT-4o-mini, pgvector similarity search, Amazon Comprehend Medical NLP entity extraction, and LLM cost quotas in DynamoDB.


Platform: Architected the production multi-tenant SaaS data model in MySQL, with role-based access control (RBAC), audit logging, and billing, serving the VitalWeave patient app, the VitalWeave clinician platform, and MySleepReport. Provisioned the distributed systems backend on AWS for VitalWeave, MySleepReport, and AroCord: serverless REST APIs (Lambda, API Gateway), the voice agent on EC2, SQS/SNS, RDS, S3, Cognito, KMS, Secrets Manager, and CloudWatch. Authored the technical plan for hospital private 5G edge AI and 6G contactless sensing with a global telecom vendor.
